Comments

15 min

A comment is a note you write inside your code, for yourself or for other people. The browser ignores it, so visitors never see it on the page.

How to write a comment

A comment starts with <!-- and ends with -->. Everything in between is part of the comment:

<!-- This is a comment -->

Comments are not shown

In this example, only the heading appears on the page. Both comments stay hidden:

<!-- This is the main title of the page -->
<h1>My first page</h1>
<!-- Remember to add a paragraph here -->

Why use comments

  • To explain what a part of the page does.
  • To leave a reminder for yourself, like what you still need to add.
  • To divide a long page into clear sections.

Hide code without deleting it

You can turn code into a comment to hide it for a moment. This is called commenting out. The browser skips it, and you can bring it back any time:

<h1>My first page</h1>
<!-- <p>This paragraph is hidden for now.</p> -->

Comments on several lines

A comment can take more than one line:

<!--
  Navigation menu
  Links to the main pages
-->

Comments are not private

Anyone can open the source of your page and read your comments. Never write passwords or secrets in them.

Good habits

  • Keep comments short and useful.
  • Do not comment things that are obvious.
  • Update or delete a comment when the code changes.

Quick recap

  • A comment starts with <!-- and ends with -->.
  • The browser ignores comments, but anyone can read them in the page source.
  • You can comment out code to hide it without deleting it.

Need a hint?

A comment starts with a less-than sign, an exclamation mark and two dashes, and ends with two dashes and a greater-than sign. Put the whole secret paragraph inside one comment.
